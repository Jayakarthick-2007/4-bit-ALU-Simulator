How the ALU Works

ADD: The ALU adds the two 4-bit numbers starting from the least significant bit. Each bit produces a result bit and may generate a carry for the next bit.

SUB: Subtraction is performed using the two's-complement method. The second number is complemented and then added to the first number.

MULTIPLY: Binary multiplication generates partial products depending on each bit of the multiplier. The partial products are shifted and added.

AND: The output bit is 1 only when both input bits are 1.

OR: The output bit is 1 when at least one input bit is 1.

XOR: The output bit is 1 when the input bits are different.

NAND: NAND is the complement of AND.

NOR: NOR is the complement of OR.

XNOR: XNOR is the complement of XOR. The output is 1 when both input bits are equal.
