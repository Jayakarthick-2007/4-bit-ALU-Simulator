# ⚡ 4-Bit ALU Step-by-Step Simulator

An interactive web-based **4-Bit Arithmetic Logic Unit (ALU) Simulator** developed as a Computer Organization and Architecture project.

## 🚀 Features

The simulator performs:

* Addition (ADD)
* Subtraction (SUB)
* Multiplication (MULTIPLY)
* AND
* OR
* XOR
* NAND
* NOR
* XNOR

## 🧮 Step-by-Step Learning

The main purpose of this project is to understand how an ALU performs binary operations internally.

For arithmetic operations, the simulator demonstrates:

* Bit-by-bit addition
* Carry propagation
* Borrow during subtraction
* Two's complement concept
* Binary multiplication
* Partial products

For logical operations, it demonstrates the operation performed on each individual bit.

## 💻 Technologies Used

* HTML
* CSS
* JavaScript

No external libraries or frameworks are required.

## ▶️ How to Run

1. Download or clone this repository.
2. Open `4_bit_alu_learning_simulator.html` in a web browser.
3. Enter two 4-bit binary numbers.
4. Select an ALU operation.
5. Click **NEXT STEP** to understand the calculation step by step.
6. Click **SHOW ALL STEPS** to complete the operation.

## 📌 Example

Input A:

`1101` = 13

Input B:

`0111` = 7

For addition:

```text
   1101
 + 0111
 -------
  11010
```

The 4-bit ALU output is:

```text
1010
```

with a final carry of:

```text
1
```
